# Bulawayo Water Usage Data Analysis

## Overview
This project is a SQL Relational Database application designed to analyze
household water usage data in Bulawayo. The system helps identify water
consumption patterns, high-usage households, and supports data-driven
decisions for improved water distribution.

## Problem Statement
Bulawayo experiences frequent water shortages, and there is no centralized,
data-driven system to track household water usage. This makes it difficult
to identify overconsumption and plan fair water distribution.

## Solution
A relational database was designed and implemented using MySQL. The database
stores information about suburbs, households, daily water usage records,
and alerts for high consumption. SQL queries were written to analyze trends,
calculate averages, and identify households with unusually high water usage.

## Database Structure
The database consists of the following tables:
- Suburbs
- Households
- Water_Usage
- Alerts

Primary and foreign keys are used to enforce relationships and maintain
data integrity.

## Key Features
- Calculates total water usage per suburb
- Computes average household water usage
- Identifies high water usage households
- Tracks daily water consumption trends
