# Bulawayo Water Usage Data Analysis

## Project Overview
This project analyzes household water usage in Bulawayo using MySQL.
The goal is to identify water consumption patterns, high-usage households,
and support better water distribution decisions.

## Problem Statement
Bulawayo experiences frequent water shortages and lacks a data-driven
approach to monitor household water usage and identify overconsumption.

## Solution
A relational MySQL database was designed to store suburbs, households,
water usage records, and alerts. SQL queries were used to analyze trends
and identify high water usage.

## Tools Used
- MySQL
- VS Code
- GitHub

## Key Analysis
- Total water usage per suburb
- Average household water usage
- High water usage alerts
- Daily water usage trends
